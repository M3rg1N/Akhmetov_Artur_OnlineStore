# OnlineStore – интернет-магазин на WPF

**OnlineStore** – настольное приложение интернет-магазина на C# с графическим интерфейсом WPF и базой данных SQL Server.

## Возможности

- Регистрация и авторизация пользователей.
- Просмотр каталога, поиск, фильтрация и сортировка товаров.
- Корзина и оформление заказов.
- Личный профиль и история заказов.
- Управление товарами, заказами и ролями через панель администратора.

## Установка

1. Установите Visual Studio с поддержкой разработки на .NET, **.NET 10 SDK** и SQL Server.
2. Подготовьте базу данных `OnlineStore` с нужными таблицами.
3. Укажите имя своего SQL Server в строке подключения файла `Models/OnlineStoreContext.cs`.
4. Откройте `OnlineStore.slnx` в Visual Studio, восстановите NuGet-пакеты и запустите проект.

## Использование

После запуска зарегистрируйтесь или войдите в учётную запись. В каталоге выберите товары и добавьте их в корзину, затем оформите заказ. В профиле можно изменить личные данные и посмотреть историю покупок. Функции управления доступны пользователям с соответствующими ролями.

## Структура проекта

- `MainWindow.xaml` – окно авторизации и регистрации.
- `Pages/` – каталог, корзина, профиль и панель управления.
- `Models/` – модели данных и контекст Entity Framework Core.
- `Helpers/` – вспомогательные классы для паролей, заказов и подтверждения контактов.
- `Database/` – дополнительные SQL-скрипты.

## Данные

Данные пользователей, товаров, категорий и заказов хранятся в **SQL Server**. Для работы с базой применяется **Entity Framework Core**.
